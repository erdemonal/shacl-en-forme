    Method and limitations

    • The sampling frame is public GitHub repositories returned by the configured search queries.
    • Verification uses the canonical SHACL namespace http://www.w3.org/ns/shacl#.
    • The primary content analysis counts one observation per unique Git tree.
    • Malformed RDF is not repaired. Inaccessible content is excluded from the counts.
