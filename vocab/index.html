SHACL en Forme Vocabulary

Namespace: https://w3id.org/shacl-en-forme/vocab#

Preferred prefix: sef

Machine-readable: index.ttl · Dataset: stats.jsonld · Project: SHACL en Forme

Terms used by the SHACL en Forme usage-statistics dataset. Based on SHACL 1.0.

Classes

AnalysisResults
https://w3id.org/shacl-en-forme/vocab#AnalysisResults A dataset of measured SHACL 1.0 usage statistics over a corpus of Git trees.

Corpus size

intended_unique_verified_trees
https://w3id.org/shacl-en-forme/vocab#intended_unique_verified_trees Number of distinct verified Git trees in the intended corpus.
extracted_unique_trees
https://w3id.org/shacl-en-forme/vocab#extracted_unique_trees Number of distinct Git trees successfully extracted for analysis.
lower_bound
https://w3id.org/shacl-en-forme/vocab#lower_bound True when reported counts are conservative lower bounds due to incomplete extraction or parsing.

Counting primitives

predicate
https://w3id.org/shacl-en-forme/vocab#predicate The SHACL predicate or IRI whose usage is counted.
occurrences
https://w3id.org/shacl-en-forme/vocab#occurrences Number of observed occurrences of a counted phenomenon in extracted trees.
unique_trees
https://w3id.org/shacl-en-forme/vocab#unique_trees Number of distinct extracted Git trees in which a phenomenon was observed.
percent_of_extracted_trees
https://w3id.org/shacl-en-forme/vocab#percent_of_extracted_trees unique_trees as a percentage of extracted_unique_trees.
verified_repositories
https://w3id.org/shacl-en-forme/vocab#verified_repositories Number of verified GitHub repositories associated with trees that exhibited a phenomenon.
percent_of_verified_repositories
https://w3id.org/shacl-en-forme/vocab#percent_of_verified_repositories verified_repositories as a percentage of all verified repositories in the corpus.
denominator_extracted_trees
https://w3id.org/shacl-en-forme/vocab#denominator_extracted_trees Tree population used as denominator for tree-based rates.
denominator_verified_repositories
https://w3id.org/shacl-en-forme/vocab#denominator_verified_repositories Repository population used as denominator for repository-based rates.
total_occurrences
https://w3id.org/shacl-en-forme/vocab#total_occurrences Sum of occurrences across a result group.
numerator
https://w3id.org/shacl-en-forme/vocab#numerator Numerator of a rate.
denominator
https://w3id.org/shacl-en-forme/vocab#denominator Denominator of a rate.
micro_rate
https://w3id.org/shacl-en-forme/vocab#micro_rate Micro-averaged rate equal to numerator divided by denominator.
rate
https://w3id.org/shacl-en-forme/vocab#rate Proportion of labelled items within a stated population.
n_with_label
https://w3id.org/shacl-en-forme/vocab#n_with_label Number of items carrying a given classification label.

Shapes

node_shapes
https://w3id.org/shacl-en-forme/vocab#node_shapes Count of resources typed as sh:NodeShape.
property_shapes
https://w3id.org/shacl-en-forme/vocab#property_shapes Count of resources typed as sh:PropertyShape.
distinct_shapes
https://w3id.org/shacl-en-forme/vocab#distinct_shapes Count of distinct resources typed as sh:NodeShape and/or sh:PropertyShape.
shape_documents
https://w3id.org/shacl-en-forme/vocab#shape_documents Number of RDF documents that contain SHACL shapes.
trees_with_shape_documents
https://w3id.org/shacl-en-forme/vocab#trees_with_shape_documents Number of extracted Git trees that contain at least one shape document.
content_sha256_groups
https://w3id.org/shacl-en-forme/vocab#content_sha256_groups Number of distinct document contents after SHA-256 deduplication.

SPARQL

sparql_links
https://w3id.org/shacl-en-forme/vocab#sparql_links Number of sh:sparql links observed in extracted trees.
sparql_constraint_nodes
https://w3id.org/shacl-en-forme/vocab#sparql_constraint_nodes Number of SPARQL constraint nodes observed in extracted trees.
sparql_target_trees
https://w3id.org/shacl-en-forme/vocab#sparql_target_trees Number of extracted Git trees with SPARQL-based targets.

Property paths

nested_forms_counted_separately
https://w3id.org/shacl-en-forme/vocab#nested_forms_counted_separately True when nested SHACL property-path forms contribute separate occurrence counts, so form occurrence totals may exceed path declaration totals.
form
https://w3id.org/shacl-en-forme/vocab#form Name of a SHACL 1.0 property-path form, such as PredicatePath or SequencePath.
path_declarations
https://w3id.org/shacl-en-forme/vocab#path_declarations Number of sh:path declarations observed in extracted trees.
classified
https://w3id.org/shacl-en-forme/vocab#classified Number of path declarations classified into one of the seven SHACL 1.0 property-path forms.
unclassified
https://w3id.org/shacl-en-forme/vocab#unclassified Number of path declarations not classified into a SHACL 1.0 property-path form.

Ontology alignment

both_stream_trees
https://w3id.org/shacl-en-forme/vocab#both_stream_trees Number of extracted Git trees that contribute both shapes-stream and ontology-stream evidence used by alignment rates.

primary_closed02_confirmed
